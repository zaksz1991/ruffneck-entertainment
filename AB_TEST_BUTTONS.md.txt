# A/B test — primary button colors

## Variants
| Variant | Look | CSS |
|---------|------|-----|
| **A** | Brand cyan bg, navy text | `#00B4D8` / text `#0B1E3A` |
| **B** | Teal bg, white text | `#0D9488` / text `#FFFFFF` |

## How it works
- 50/50 random assignment on first visit
- Stored in `localStorage` key `rn_btn_ab` (sticky per browser)
- `data-rn-btn="A|B"` on `<html>`

## Force a variant (testing)
- `?rn_btn=A` or `?rn_btn=B` in the URL
- Or console: `rnBtnAb.set('B')`

## Analytics
If Google Analytics (gtag) is present, events fire:
- `rn_btn_ab_exposure` — page view with variant
- `rn_btn_ab_click` — primary button click with label + variant

In GA4: Explore → create comparison on event parameter `btn_variant`.

## Winner decision
After enough clicks (e.g. 100+ per variant), prefer the variant with higher click-through on main CTAs (Book a Consultation, Book a Call, Get Started).
Then remove the test and keep the winner as default CSS.
