# WhatsApp Business API vs what we implemented

## What is live on the website (FREE)

Pre-filled WhatsApp links (`wa.me`) with professional message templates:

- Consultation
- CV / LinkedIn
- IT Support
- AI Training
- Warehouse template request
- Internship / Volunteer
- General enquiry

These open the visitor’s WhatsApp with a ready message. No Meta API, no monthly fee.

JavaScript helper: `window.RN_WA.link('consultation')` or `RN_WA.open('cv')`.

## Full WhatsApp Business API (NOT free to skip setup)

To send **template messages** initiated by your business (outside the 24h window), you need:

1. Meta Business Manager account
2. WhatsApp Business Platform (Cloud API) app
3. Verified business + phone number
4. Approved message templates in Meta
5. A server or serverless function to call the API with a permanent token

### Official Cloud API (high level)

POST https://graph.facebook.com/v21.0/{PHONE_NUMBER_ID}/messages

Headers:
  Authorization: Bearer {ACCESS_TOKEN}
  Content-Type: application/json

Body example (template):
{
  "messaging_product": "whatsapp",
  "to": "2348033807856",
  "type": "template",
  "template": {
    "name": "hello_world",
    "language": { "code": "en_US" }
  }
}

### Providers (if not using Cloud API directly)

- Meta WhatsApp Cloud API (direct)
- 360dialog, Twilio, MessageBird, etc. (often paid)

### Vercel serverless sketch (only after you have token)

api/whatsapp-send.js — do NOT commit tokens; use env:
  WHATSAPP_TOKEN
  WHATSAPP_PHONE_NUMBER_ID

Until Meta approves templates and you set env vars, use the free wa.me template buttons on the site.
