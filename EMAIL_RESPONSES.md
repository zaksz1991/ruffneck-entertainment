# Client Email Auto-Replies (Commercial Grade)

After you paste `RuffNeck_CMS_Script.gs` into Apps Script and redeploy, clients receive branded HTML emails for:

## 1. Free Guide (Lead Magnet)
- Subject: Your free guide: 20 AI Prompts...
- PDF button + optional attachment
- Secondary CTA: Book consultation

## 2. Webinar “Notify Me”
- Subject: You're on the list — AI Literacy Webinar Series
- What to expect
- Link to free PDF while waiting

## 3. Blog Newsletter
- Subject: You're subscribed — RuffNeck Insights
- Short professional confirmation

## 4. Contact form (auto-detects intent from service + message)

| Intent | Trigger words / service | Client receives |
|--------|-------------------------|-----------------|
| **Partnership / Sponsor** | partner, sponsor, collaboration… | Partnership thank-you + 1–2 business day response |
| **Quote** | quote, pricing, proposal, estimate… | Quote received + Calendly CTA |
| **Consultation** | consult, advisory, strategy, discovery… | Consultation + Schedule call button |
| **General message** | anything else | Standard receipt + free guide / call links |

You also get an owner email tagged e.g. `[PARTNERSHIP]`, `[QUOTE]`, `[CONSULTATION]`, `[GENERAL]`.

## Branding on every email
- Navy header + cyan brand name
- Founder signature block
- WhatsApp, email, website
- CAC / SMEDAN line

## Deploy reminder
1. Paste full `RuffNeck_CMS_Script.gs`
2. Save → Run `setup` if needed
3. Deploy → **New version** → Anyone
4. Test each form with your own email
