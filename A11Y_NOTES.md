# Accessibility implementation

## Done in this package
- Skip link on major pages
- :focus-visible outlines
- prefers-reduced-motion rules
- main id targets for skip link
- lang="en" where missing
- Menu button aria-label patterns
- Accessibility statement updated

## Manual checks (you)
1. Keyboard-only: Tab across home, blog, store, contact
2. Zoom to 200% on mobile width
3. Optional: WAVE or axe browser extension on /
4. Confirm form fields have visible labels

## Not claimed
Full WCAG 2.2 AA certification requires formal audit; this is progressive improvement.
